# 掘金基本面字段说明（中文注释）

本说明对应 `query_fundamentals.py` 使用的掘金财务接口字段，便于扩展 `--balance-fields`、`--income-fields`、`--cashflow-fields`、`--prime-fields`、`--deriv-fields` 时查阅。完整字段以 [掘金文档](https://www.myquant.cn/docs2/sdk/python/API介绍/股票财务数据及基础数据函数（免费）.html) 为准。

---

## API 使用说明

### 1. 掘金 API 直接调用

调用前必须先设置 token：`gm.api.set_token("你的token")`。以下为 Python 中直接使用掘金 SDK 的用法。

**截面接口（单日、单报告期，point-in-time）**

| 接口 | 说明 | 主要参数 | 返回值 |
|------|------|----------|--------|
| `stk_get_fundamentals_balance_pt` | 资产负债表截面 | `symbols`（str 或 list，如 `'SHSE.600000'`）、`fields`（逗号分隔）、`date`（YYYY-MM-DD，None=最新）、`df=True` | `pd.DataFrame`，列含 symbol, pub_date, rpt_date, rpt_type, data_type 及 fields 对应列 |
| `stk_get_fundamentals_income_pt` | 利润表截面 | 同上 | 同上 |
| `stk_get_fundamentals_cashflow_pt` | 现金流量表截面 | 同上 | 同上 |
| `stk_get_finance_prime_pt` | 财务主要指标截面 | 同上 | 同上 |
| `stk_get_finance_deriv_pt` | 财务衍生指标截面 | 同上 | 同上 |

**多报告期接口（按报告日区间）**

| 接口 | 说明 | 主要参数 | 返回值 |
|------|------|----------|--------|
| `stk_get_fundamentals_balance` | 资产负债表多期 | `symbol`（单只，如 `'SHSE.600000'`）、`fields`、`start_date`、`end_date`（YYYY-MM-DD）、`df=True` | `pd.DataFrame`，多行，每行一报告期 |
| `stk_get_fundamentals_income` | 利润表多期 | 同上 | 同上 |
| `stk_get_fundamentals_cashflow` | 现金流量表多期 | 同上 | 同上 |
| `stk_get_finance_prime` | 财务主要指标多期 | 同上 | 同上 |
| `stk_get_finance_deriv` | 财务衍生指标多期 | 同上 | 同上 |

**通用参数说明**

- **symbols / symbol**：掘金标的代码，沪市 `SHSE.600000`、深市 `SZSE.000001`；截面可多只逗号分隔或 list，多期仅单只。
- **fields**：逗号分隔的字段名，单次最多约 20 个，见下文各表字段。
- **date**：截面查询日期（发布日期），不传或 None 表示最新可用。
- **start_date / end_date**：多期时为报告日区间，闭区间。
- **rpt_type**：可选，1=一季报、6=中报、9=三季报、12=年报，不传则不限。
- **data_type**：可选，102=合并调整（推荐）、101=合并原始等，不传则默认合并调整。
- **df=True**：返回 `pd.DataFrame`；否则返回 `list[dict]`。

**示例（截面）**

```python
from gm.api import set_token, stk_get_fundamentals_balance_pt, stk_get_finance_prime_pt

set_token("你的token")
# 单只股票，最新报告期
df_balance = stk_get_fundamentals_balance_pt(
    symbols="SHSE.600089",
    fields="ttl_ast,ttl_liab,ttl_eqy",
    date=None,
    df=True
)
df_prime = stk_get_finance_prime_pt(
    symbols="SHSE.600089",
    fields="roe,inc_oper,net_prof_pcom",
    date="2024-06-01",
    df=True
)
```

**示例（多报告期）**

```python
from gm.api import set_token, stk_get_finance_prime

set_token("你的token")
df = stk_get_finance_prime(
    symbol="SHSE.600089",
    fields="inc_oper,net_prof_pcom,roe",
    start_date="2022-01-01",
    end_date="2024-12-31",
    df=True
)
# df 多行，每行 rpt_date, rpt_type 及上述字段
```

### 2. 脚本内编程调用（query_fundamentals）

在代码中 `import` 本脚本提供的函数，可复用默认字段与多期/增长率逻辑，无需手写掘金多表调用。

**导入**

```python
from gm_strategy.query_fundamentals import query_fundamentals, print_report
# 需先设置 token，例如：
import os
os.environ["GM_TOKEN"] = "你的token"
# 或在调用前：from gm.api import set_token; set_token("你的token")
```

**截面查询（单日）**

```python
data = query_fundamentals(
    "600089",                    # 或 "SHSE.600089"
    date="2024-06-01",           # None 表示最新
    balance_fields=None,         # None=默认字段；或 "+goodwill" 追加；或 "ttl_ast,ttl_liab" 替换
    income_fields=None,
    cashflow_fields=None,
    prime_fields=None,
    deriv_fields=None,           # 不传则不请求衍生指标；传 "roe,roa" 则请求
    add_yoy=True,                # 仅多期时生效
)
# 返回 dict：symbol, date, balance, income, cashflow, prime, deriv（均为 DataFrame 或 None）
print_report(data)              # 打印可读报告
```

**多报告期查询（含同比增长率）**

```python
data = query_fundamentals(
    "600089",
    start_date="2022-01-01",
    end_date="2024-12-31",
    add_yoy=True,                # 对 prime 表计算同比，新增 * _yoy 列
    deriv_fields="roe,roa",      # 可选
)
# 返回 dict：symbol, start_date, end_date, balance, income, cashflow, prime, deriv
# prime 若有多行且 add_yoy=True，会多出 inc_oper_yoy、net_prof_pcom_yoy 等列
print_report(data)
```

**返回结构说明**

| 键 | 说明 |
|----|------|
| symbol | 标准化后的标的代码，如 SHSE.600089 |
| date | 截面时的查询日期（或 None） |
| start_date / end_date | 多期时的报告日区间（仅多期时有） |
| balance | 资产负债表 DataFrame 或 None |
| income | 利润表 DataFrame 或 None |
| cashflow | 现金流量表 DataFrame 或 None |
| prime | 财务主要指标 DataFrame 或 None；多期且 add_yoy 时含 _yoy 列 |
| deriv | 财务衍生指标 DataFrame 或 None（仅当传入 deriv_fields 时可能有） |

## 五、财务衍生指标（deriv）

接口：`stk_get_finance_deriv_pt` / `stk_get_finance_deriv`（多期）。**仅当传入 `--deriv-fields` 时请求**，字段名以掘金文档为准，以下为常见示例。

| 字段名 | 中文名称 | 说明 |
|--------|----------|------|
| roe | 净资产收益率 | 衍生口径 |
| roa | 总资产收益率 | 衍生口径 |
| gross_margin | 毛利率 | 若接口支持 |
| net_margin | 净利率 | 若接口支持 |
| oper_prof_margin | 营业利润率 | 若接口支持 |

注：掘金财务衍生表可能还包含估值类（如市盈率、市净率）等，具体以官网「财务衍生指标」表为准。

---

## 六、多报告期与增长率

- **多报告期**：使用 `--start-date` 与 `--end-date` 时，脚本调用上述各表的**非 _pt** 接口，按报告日区间返回多期数据。
- **同比增长率**：多报告期下脚本会对「财务主要指标」表按**上年同期**（同一报表类型、报告日差一年）计算增长率，新增列名为 `原列名_yoy`（如 `inc_oper_yoy`、`net_prof_pcom_yoy`）。无需时可加 `--no-yoy`。
